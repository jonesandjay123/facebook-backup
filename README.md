# Facebook 貼文備份

本人 Facebook 貼文的個人備份（僅收錄自己發表的貼文，不含他人貼在牆上的內容）。

- 總篇數：500
- 時間範圍：2015/2015- ～ 2026/2026-
- 留言總數：815
- 備份時間：2026-09-19 09:26（美東時間）

## 目錄結構

- 以年份分資料夾：`2016/`、`2017/`……
- 每篇貼文一個 Markdown 檔，檔名格式：`YYYY-MM-DD-<貼文ID>.md`（按日期排序）
- 每篇內容包含：發文時間、原文連結、反應統計、全文、圖片文字辨識、留言（含留言時間與直達連結）

## 已知限制

- 照片與影片的原檔無法透過工具取得，需另用 Facebook 官方「下載你的資訊」備份。
- 留言的回覆串內容無法透過工具取得，僅記錄回覆則數。
