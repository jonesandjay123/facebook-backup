# Facebook 貼文備份

本人 Facebook 貼文的個人備份。

> 注意：本備份為經由串接工具／瀏覽器取得的部分匯出（partial export），不保證為帳號完整歷史。

- 已備份篇數：994（部分匯出；稽核發現 2022／2021／2024 等年份尚有缺口，實際發文總數高於此數，完整總數待稽核完成後確認）
- 時間範圍：2015-03-31 ～ 2026-08-10（含 2023 年補回的 34 篇）
- 留言總數：1305
- 備份時間：2026-09-19 10:23（美東時間）

## 目錄結構

- 以年份分資料夾：`2016/`、`2017/`……
- 每篇貼文一個 Markdown 檔，檔名格式：`YYYY-MM-DD-<貼文ID>.md`（按日期排序）
- 每篇內容包含：發文時間、原文連結、反應統計、全文、圖片文字辨識、留言（含留言時間與直達連結）
- `2023/` 另含朋友在動態時報上的生日祝福與被標註貼文；其餘年份僅收錄自己發表的貼文。

## 已知限制

- 照片與影片的原檔無法透過工具取得，需另用 Facebook 官方「下載你的資訊」備份。
- 留言的回覆串內容無法透過工具取得，僅記錄回覆則數。
- 2023 年部分留言的作者名稱無法透過工具取得，以「未知」標示。
