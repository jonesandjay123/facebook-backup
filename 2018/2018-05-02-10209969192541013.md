# 大家都認識瓊瑤，不過相信很少人知道瓊瑤有段介入出

大家都認識瓊瑤，不過相信很少人知道瓊瑤有段介入出版社老闆婚姻，從小三轉正的過往...

我一位當兵的朋友，剛好就是該出版社老闆的孫子。不過朋友的奶奶不是瓊瑤，而是老闆的元配—林婉珍。

每次看朋友提到瓊瑤，總沒一句好話...
由於瓊瑤的名聲優勢，讓她總握有對外發語權的優勢，加上又有外遇老公在撐腰，所以處處打壓著朋友奶奶。

朋友的奶奶，在這段小三高調介入家庭的婚姻中，是為了孩子才選擇忍氣吞聲...

____________

幾天前剛好關鍵時刻節目上介紹到了這本新書—往事浮光。(可能是業配吧，因為那天剛好開始可以預購~XD)我立刻就發現，這剛好也就是我朋友每次都想要分享出來讓大家知道的故事！

林婉珍奶奶，以前選擇沉默不講，都是讓別人來說。如今五十年過去，這次她決定以自傳的形式、自己的角度，告訴大家在這段婚姻中所承受的種種委屈...

____________

我喜歡聽真人真事的故事，尤其又是朋友的奶奶，且也是他一直想讓大家知道的事。所以當然立馬就去預購了書～

昨晚一上架，回家就熬夜把它給讀完。
當中其實講瓊瑤介入婚姻的部分也只佔了大概三分之一的篇幅而已。主要還是以林婉珍奶奶自己從小到大成長的自傳形式在推進。

除了佩服朋友奶奶為了老公的事業犧牲奉獻、為了給孩子一個完整的家庭而隱忍的偉大之外，我也很喜歡她前半段純粹述說自己成長故事的那些篇幅。很有畫面，讓人彷彿一同置身在早期那樣民風純樸的年代，一同隨著時光的變遷，追憶過往...

難怪這書名取叫做往事浮光呀！
