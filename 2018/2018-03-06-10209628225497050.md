# 住房租套房其中一個有趣的一點，就是信箱很快就會塞

住房租套房其中一個有趣的一點，就是信箱很快就會塞滿。而且大多時候寄來的都不是自己的信...

也許大家都懶，所以通常會固定一陣子去開信箱檢查的都是我。我習慣順手挑出廣告丟掉(然後把折價券之類的自己拿走...XD)，再把剩下的信件放在公共區域給其他室友們自己領回～

大多時候看到的信件不外乎都是金融、保險或繳費有關的。我一直很好奇，這些人到底還有沒有住在這裡?還是根本就已經跑路了...XD
