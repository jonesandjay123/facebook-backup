## 方法
- Facebook 動態時報 2021 年篩選，逐段列舉 canonical URL。
- 每篇以 `facebook-cli post read --url` 解析 post ID，作者取 `author_name`/`username`。
- 日期以 Facebook 畫面顯示的美東本地日期為準；CLI 回傳為 UTC，容許 ±1 日差（皆在容許內，本次 0 件超出）。
- 與 repo `2021/` 檔名（`YYYY-MM-DD-<postID>.md`）雙向比對。
