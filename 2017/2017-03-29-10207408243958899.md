# 我蠻喜歡來家裡附近這間可以吃很飽的拉麵用餐。平均

我蠻喜歡來家裡附近這間可以吃很飽的拉麵用餐。平均大概一個禮拜來一次吧～

這間店除了最有名的特色是份量超大之外！常來的客人也會知道，他們對於份量供給的部分也是蠻堅持(蠻計較的)...

因為他們給的麵真的挺多，所以第一次來吃的時候還不是那麼習慣，於是詢問是否可以幫我加一點湯。店員說，他們店裡規定的提供份量是固定200克，所以無法配合～

沒差，不給加湯這件事，並不會影響我喜歡來這邊"吃飽"的意願...所以還是經常來！

之後幾次來，也還是偶爾會再聽到有客人要求要加湯，然後都被所謂的“200克回答”給打槍...

_______________________

印象很深刻，有次我左邊一位太太，就因為加湯不成、抱怨也無效，最後吃的火氣都上來，然後咬了幾口就回家了...

另外，上次帶朋友來時，朋友因為禽流感不想吃蛋，所以也問了煮麵師傅可否把蛋換成其他配料~
但如我所料的，他被拒絕了..XD

朋友不放棄，繼續追問，那可否至少把蛋分給我?
結果還是沒有成功...
麵端上來時，就只是朋友的碗裡少了顆蛋、而我的蛋確也沒有因而+1～

________________________

今天，我旁邊來了兩位漂亮的OL小姐。
他們點完麵後，就很熱絡的在聊天，看起來心情不錯~

突然間，右邊那位比較活潑的小姐叫住了煮師傅: 「老闆，我不吃蔥，可以把我的蔥給我朋友嗎?」

這位煮麵師傅我認得! 他就是上次打槍我朋友不給蛋的那位!!
只見煮麵師傅，拿起了訂單，猶豫了幾秒...
然後說:「嗯...好吧。」

什麼?!!!!!! 他竟然說好!!!

兩位OL小姐，向師傅道完謝以後，一派輕鬆得準備繼續聊天~

而她們似乎還不知道，自己已經不小心達成了某種艱難成就!!
而見證了這難得時刻的我，立馬跳出來跟她們兩位講"限量200克的湯"、還有"朋友吃蛋的故事"!

小姐們聽完，笑呵呵的。然後那位較活潑的小姐就突然決定要來挑戰看看能否加到湯...

結果師傅似乎也聽到了我跟小姐們說的話，所以用了比較不一樣的方式回答:「抱歉，湯的部分，目前是還沒有人成功加過喔!」
看來，"小姐攻勢"也是有極限的~XD
_______________________

雖然加蔥跟加蛋聽起來是不太一樣的東西，但A不吃分給B的道理，按理說應該都一樣。
確實沒理由蔥可以、蛋就不可以~

我自己的結論是，在請求別人時，說話的用詞、語氣及態度、甚至跟說話者本身的狀態，確實是和結果有直接關係的!
老實說上次朋友在跟店員要求換蛋時的口氣，我自己覺得沒有很好。
要是我，也可能會選擇冷處理。於是結果就是煮麵師傅裝傻刻意不把朋友的蛋加給我~

而同樣的情況，要是正妹來，稍微ㄋㄞ一下~
要是我是店長，也許就有機會小碗變大碗了吧...人之常情~XD
