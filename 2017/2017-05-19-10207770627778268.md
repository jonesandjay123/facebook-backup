# 一款還蠻喜歡，也穿很久的Uniqulo七分褲，之

一款還蠻喜歡，也穿很久的Uniqulo七分褲，之前膝蓋處破了一個小洞，最近那洞已經裂到不能穿...

於是今晚決定回來找件類似的款式，補貨一下。

____________________

這時，我忽然驚覺自己似乎已經很久沒有花錢買新褲子了！

嗯...所以到底有多久沒有買褲子？而上一次買的褲子又是什麼款式呢？

剛好，平常有記帳的習慣，確實的紀錄了每一筆的開銷。所以這好奇的疑問，是可以找的到答案的！

打開記帳APP，把範圍選到從我開始記帳的2015年起至今，類別再調成“服飾美容”下面的子類別—褲子。

馬上答案揭曉～

上一次買褲子的時間是2015年六月14日。
買的是一件790元，同樣也是uniqulo的無痕長褲。

哇，也真的是好久沒買新褲子囉！
而且看來，我真的是對Uniqulo情有獨鍾！

因為認識的牌子不多，所以總是挑它...XD
