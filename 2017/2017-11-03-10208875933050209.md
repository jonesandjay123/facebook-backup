# 公司出差人員，只要把換洗衣物放進宿舍的籃子裏，隔

公司出差人員，只要把換洗衣物放進宿舍的籃子裏，隔天就會有專人幫忙把它們洗完、摺好放還回來。
算是一個很貼心的服務！

昨晚拿回來時，覺得跟平常不太一樣，襪子不見了？！

不過想想算了，可能是房務人員東西太多，不小心忘了吧～

沒想到今天回房裡，看到籃子除了洗回來的衣物外，還多了一張紙條:
「你好：你襪子少一個了，不知道那去了！如果沒了我去買一雙給你」

看了覺得既可愛、又好笑！
謝謝房務員的誠實與貼心～
其實我一點也不在意！！
