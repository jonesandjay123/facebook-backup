# 晚上騎著車，在巷子裡亂竄。

晚上騎著車，在巷子裡亂竄。
忽然發現一戶人家大門敞開，在門口直接擺著魚缸、鳥籠，還有一台復古機車。

這樣整齊刻意的擺設，彷彿就是故意展示給經過的路人看似的～
好像也不擔心有人過來闖空門...

實在令人費解，為什麼要這麼做?！

探頭看了一下，感覺也不像是做生意的店家。
而門口掛著的看似招牌的東西，上面寫著“成家”兩個字到底又想表達什麼?！

忽然覺得很像電影情節，好神秘的一戶人家...
