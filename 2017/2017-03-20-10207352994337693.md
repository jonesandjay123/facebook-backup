# 搭公車時，對面坐著一位雖然年紀一把，卻仍精神奕奕

搭公車時，對面坐著一位雖然年紀一把，卻仍精神奕奕的老爺爺。
儘管天氣不太好，他仍全副武裝的要去爬四獸山。
只見他拿出智慧手機打給夥伴，用中氣十足的聲音和夥伴討論行程。
配上他包包上的迷彩軍帽，看起來挺帥的！

有時候會好奇，數十年後當自己老了，我會是什麼樣子？身體是否依然保持硬朗？
而眼前這位登山爺爺，就是一個健康老人的很好典範！
