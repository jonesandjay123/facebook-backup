# 晚上來朋友的鹹水雞攤光顧，難得看到旁邊攤的阿姨有

晚上來朋友的鹹水雞攤光顧，難得看到旁邊攤的阿姨有生意上門。

這阿姨有時賣糖葫蘆、有時賣荔枝或龍眼。
雖然我從小就看她在這個位置擺攤也已經好多年了,但印象一直都不是特別好...

有時候會看她驅趕前來排隊買朋友東西的客人，要求他們別擋住自己的生意。
偶爾也會聽到她在一旁，閒言閒語的嘟噥、碎念朋友~

但也許朋友早已習慣了這樣的鄰居，所以總是不跟阿姨計較，始終讓步配合。

而自從我上次看到阿姨偷偷撿起掉地上的糖葫蘆擺回去賣以後，就真的認定她是一個黑心商人...XD

__________________________________

不過話雖如此，我倒也不至於是討厭她!
因為畢竟每天回家幾乎都看到她，久而就之甚至有了一定程度的親切感。

所以雖然阿姨不是很好，但還挺關注她的，喜歡默默地觀察她在做什麼~
每次回家路過，也都會稍微看一下。

上個月我路過時，就看到她賣荔枝的攤子剛好來了兩位年輕的陸客女生。

我聽到其中一位女生對著她說:"我看到妳剛剛偷偷把我們挑掉的又放進去了!" (在稱重時)

哈...
完全不意外，很像是這位黑心阿姨會做的事...XD
