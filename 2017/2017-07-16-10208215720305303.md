# 快要感冒前，自己的身體似乎都會有所警訊。

快要感冒前，自己的身體似乎都會有所警訊。

應該是中午吃壽喜燒的冰淇淋怪怪的緣故，
下午開始喉嚨就不太舒服，而且直冒冷汗、也突然變得不想吹到冷氣！
我知道這就是自己快要感冒的症狀！

於是趁著下午日落前，刻意又到外頭騎車曬太陽，希望藉由排汗代謝掉體內的病毒。
另外，還要再配上大量的喝溫開水～
(故意帶保溫杯跟著出去喝)

這是每次自己在感冒前，習慣的預防法，有時候確實還挺有效，也成功地幫自己在一個晚上內迅速的好起來！

至於這次能否成功，就要看運氣，然後觀察接下來幾天的狀況囉～
(感冒雖不是什麼大病，但得到還是挺麻煩的。)
