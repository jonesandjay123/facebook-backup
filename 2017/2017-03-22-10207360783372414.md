# 公司樓下是一間叫做EzPay的電子支付公司。

公司樓下是一間叫做EzPay的電子支付公司。
剛才上樓時，和三個該公司的IT人員一同搭電梯。

其中2個比較資深的帶著另一位新進同仁提著便當正要回公司用餐。
他們簡單的問了一下新同仁的工作背景，得知這位同仁原本的工作是偏硬體方面的，是在後來另外去進修後，才進到EzPay的!

這時，其中一位前輩接著問: "是去巨匠嗎、還是資策會?"
新人搖搖頭回："聯成"
接著另一位前輩回答："喔，我是去巨匠的~"
聽起來，似乎三人都是去進修後才轉為IT人員的!!
於是，我也忍不住的亂入: "我是資策會的!!"

這時，大家的反應竟意外地不是覺得我很奇怪、打哪裡來的，而是一種驚喜之情!
"哈! 資策會，那你應該很厲害喔!"
然後，一陣短暫的惺惺相惜，接著電梯的門就開了...

_____________________________________________

原來在業界當中，還存在著這麼多跟我(我們)一樣，同樣是半路出家的IT從業人員，而大家似乎也都還混得不錯!
還有，原來像EzPay這種純軟公司，也會收進修出來的新人 (還讓我一次遇到兩三個~)

前陣子，朋友的朋友對於畢業後的求職之路感到徬徨。
於是在朋友介紹下，跑來找我請益有關進修IT技術的相關問題。
最後，因為資策會的政府補助也沒有了，於是選擇去台灣就業通所開的程式進修課程...

我想，大家都在找、在追尋一個更好的職涯道路和機會。
有時也許靠努力、有時也許是運氣。
但相信不管自己的過去是甚麼樣的經歷或背景，只要肯給自己一個機會，終將有一天能夠找到適合自己的路!!
