# 除了工作上的專案之外，以往自己私底下寫好玩的程式

除了工作上的專案之外，以往自己私底下寫好玩的程式都只能放在本機上面跑。
在本機運行的缺點，就是無法將作品分享給沒開發工具的朋友。

前陣子突然想找看看，有沒有免費的雲端平台可以讓我把專案上架，直接在網路上面跑。
後來發現亞馬遜的雲端平台AWS竟然就有一年的免費服務!

玩了幾天，最後終於順利把專案跟資料庫通通丟到運端。
算是又完成了另一個小夢想~

_________________

今天一整天都在家裡弄一個自認為不難的小專案。
原本覺得自己可以兩天就完成，結果每次花的時間都要比預估的久...
總覺得程式這種東西的耗時還挺難掌握的!!
