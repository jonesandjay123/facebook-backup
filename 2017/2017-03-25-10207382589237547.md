# 吳永志老師是資策會的Java名師。

> 類型：貼文
> 原文連結：https://facebook.com/1671124340/posts/pfbid02A5U2x2F8pZjwS44eNsuwBXmmA39Awt1rP3kC92HivBpDpF5jdQFycfKE5qkgLsmNl/

吳永志老師是資策會的Java名師。
之所以有名，是因為他非常用心的做教學！
把每個學生都當自己的孩子一樣在教，簡直可以說用生命投入在教學！
真的不誇張，有幾次還為了幫我們做惡補加強，自願無償的爆肝加課到晚上十點多...

我們EEIT85梯很幸運的，從基礎Java到後面的框架，一路都是由吳老師帶上來。也因為上班上學習氣氛佳，跟老師培養出了很不錯的默契與感情！儘管吳老師不是我們的班導，跟我們的關係卻是比導師還親！

今晚很難得，平常光是教課、做講義、來回奔走於台北與中壢，都已經忙到快沒時間的老師，特地抽空趁著週末班結束的晚上過來跟我們聚餐！
(別班學生邀他都邀不到，他說真的是因為跟我們班感情比較好才特地撥空的喔！)

_______________________

雖然跟長輩一同用餐多少覺得比較拘謹，不過也因而聽到吳老師分享不少平常上課時沒有機會講到的話題！

我認為今天學到最重要的一點是，老師以自己十多年來始終沒有改變初衷的教學態度，再次提醒了我們，做事情最重要的是”態度”(意指凡事用心盡力去做，哪怕沒有人看得見也一樣)。

確實，老師真的是一個在小細節都很用心堅持要做到最好的人，而這樣的堅持真的令人敬佩！

最後，因為分母少了兩位，加上大家執意不讓老師出錢，所以這一餐即使沒有特別好吃而一人又要破千...
可是能跟一位這麼好的啟蒙老師再次相聚吃飯，卻也是非常值得！！
相信只要給老師教過的同學都會認同我，吳老師真的是我們IT路上的一位明師！
