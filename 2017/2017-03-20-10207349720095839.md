# 之前看朋友分享去埃及旅行時隨手做的筆記，其中看到

之前看朋友分享去埃及旅行時隨手做的筆記，其中看到了幾張現場畫下的塗鴉，除了有上黑線外、還有色鉛筆的塗色！

向朋友確認後她告訴我，她旅行時有隨身帶著色鉛筆的習慣。天呀，好文青！！

雖然這半年來因為有上課的緣故，都有在碰色鉛筆，也有幾次隨課程同行寫生的經驗，不過隨身帶色鉛筆這種習慣倒是沒有...
______________________

昨天到三創園區時，剛好一樓有賣一些寶可夢的文具，逛了一下發現這個叫做”筆捲“的東西！

除了剛好是自己喜歡的寶可夢、又很可愛，剛好可以讓我把鐵盒裡的色鉛筆裝進去攜帶！！！
今晚是社大速寫課，所以就馬上來試試看吧～
