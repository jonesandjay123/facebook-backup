# 前幾天去阿姨家作客時遇到一對夫婦。

前幾天去阿姨家作客時遇到一對夫婦。
他們很巧地就在我家樓下夜市開夾娃娃機的店。

聽他們分享在夜市裡找店面租的狀況。
得知原來通話夜市的租金，和士林饒河比起來，已算是親切許多！

而且在夜市鬧區的店面總是人人搶著租。
一個店家做不下去倒，總會有別人來接手～
地段越好，越是一堆人排隊想要租...
____________________

想起昨天才說要收掉的漫畫店、再看看今天路過時，已經新開幕的麵包店～

完全訴說著舊的不去、新的不來的道理！

前天早上路過時，他們明明還在裝修的說...
(這間的前身是「快樂鹽酥雞」)
