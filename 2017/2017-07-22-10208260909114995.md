# 之前吳淡如等名人，分享了有關坐桃園捷運，發現沒什

之前吳淡如等名人，分享了有關坐桃園捷運，發現沒什麼人搭乘的新聞；接著前幾天，又有世大運選手村相關的新聞，寫到了桃捷沿線的林口。說林口是空屋率最高的地方...
________________________

剛好這陣子，因為發現一班免費接駁車的關係，自己也開始變得蠻常跑林口...
發現它還真是一個人口密度頗低、卻也反而逛起來覺得很舒服的地方！

譬如今天中午(約12：30左右，本應該是週末假日用餐時間的巔峰時段)我跟朋友在桃捷林口A9站出口這邊的美食廳用餐。竟發現用餐區的位子不但沒有被坐滿，反而還有很多剩下來的空位！！

照理說，這邊用餐環境好、又是位在林口捷運站的出口處，人潮應該要更多一點才對！

上次同樣是週末中午來，也一樣是人很少的狀況～
可見林口平常真的沒什麼人呀！(三井Outlet除外...)
但也因此讓我很享受在這騎車吹風、舒適悠遊的清閒感！

跟朋友說好，下次若要約下棋，就直接來這邊的美食廳下就好了！

人不多、空間寬敞、高挑視野(位在四樓)環境媲美星巴克、又有免費接駁車直接到、Youbike半小時內不用錢！這麼極品的下棋地點，還能去哪裡找呀！！
