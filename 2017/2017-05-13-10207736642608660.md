# 昨晚在樓下的大垃圾桶旁，看到了兩隻被丟棄的布娃娃

昨晚在樓下的大垃圾桶旁，看到了兩隻被丟棄的布娃娃。今早出門時，他們還在。

仔細看小鴨的屁股，破了一個大洞，絨毛外露。想必是因為這樣所以被拋棄...
旁邊另一隻狗狗，應該也是因類似的理由所以主人也不要了...

看到可愛娃娃被丟棄在垃圾堆裡，我的第一個感覺是憐憫與不捨，覺得他們這樣實在太可憐！

___________________________

可是後來再仔細想想，發現奇怪？
為何同樣都是被丟棄，我不會對旁邊的披薩盒或全聯福利中心的袋子感到可憐，而只因為娃娃是具有形象意義的存在，所以就對他們有了不同程度的憐憫之心？！

更進一步的想，如果今天小鴨是以組裝前，還未成型的袋裝棉花、黃色絨毛的形式被丟掉，我還會有同樣感覺嗎？
不，那我可能就連看都不會多看一眼...

換句話說，我會把”壞掉的娃娃被丟棄”視作一件殘忍的行為，卻對“披薩盒超商塑膠袋被丟棄“視作裡所當然！

__________________________

想想，之所以會產生這樣感受上差異的因素，是因為人類習慣性上的刻板印象與情感投射所導致的！

看到娃娃，我們的刻板印象會與純真、可愛做連結，再加上他們擁有討喜的外型，於是我們的潛意識又很自然的把可愛動物的生命投射了給他們，進而把他們跟真正的生物做類比。因此，當看到他們被丟棄時，就產生了彷彿真的小動物被拋棄了的同情感...

雖說，當我意識到這一切只是自己腦中的情感作祟時，頓時間有種忽然間清醒過來的感覺。
(不再覺得娃娃很可憐...)

但事後想想，其實人類這種習慣性為情感作連結的特質，其實也不是壞事。
它這反而造就了我們，讓我們擁有著所謂的“人性”。

人工智慧雖然不斷的進步，也越變越聰明！但相信，它們是很難模仿我們所擁有的情感與其後續所衍生出來的變異(例如同情、情緒性、倦怠感、懊悔等等)。

這種感情、與投射正是我們人類大腦奧妙的功能之一，也讓我們之所以為人！
