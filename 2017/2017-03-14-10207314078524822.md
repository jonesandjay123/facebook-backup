# 一位有緣的同學，我們高中、大學都同校。

> 原文連結：https://facebook.com/1671124340/posts/pfbid0yLCorALEn1FamhaBUPWYZ2v9cQS2eew32iTGjqVtUMDTxgvrcv1wSwWtdhGbMtCel/
> 反應：17（count reaction_type）

一位有緣的同學，我們高中、大學都同校。
畢業後他為了一圓從醫的理想，成為了全職的考生，每天勤跑補習班、圖書館埋首苦讀，努力拼考高雄醫學大學一年一度的學士後西醫。

他常常因為要專心讀書而無法和我們赴約出遊。印象深刻的是，就連去年跨年夜難得有朋自遠方來，大夥兒相約出遊聚餐，他也因為要拼讀書進度而無法前來...

他努力了好多回，但每次都以幾分之差，與錄取擦身而過...
幾年過去，我們這些朋友們，看著他這樣日以繼夜，每天努力苦讀，一心只為有朝一日可以進入醫學院的決心。一方面是佩服他的堅定與勇氣、另一方面卻也同時看了感到不捨，但又不方面予以勸阻。因為畢竟，那是人家的夢想！
____________________________

去年年底，這位友人跟我們說他決定給自己設立一個停損點！
今年雖然一樣會去拼六月的學士後西醫考，但是另一方面，他也同時報名了研究所考試。如果西醫再沒上，就去讀個研究所！

而這研究所清單，他只設定了“台清交成”這四所！

一開始聽到他直接把目標設為這四所最高學府時，我自己還覺得:“應該不是這麼容易吧？！”

____________________________

上個月他陸續去參加了該“四大”研究所的入學考。

考完後他告訴我，跟他平時準備“後西醫”的題目比起來，根本簡單太多...

於是他進而希望自己能拼出四所全上的紀錄！！

結果他真的成功了！！

可見後西考試有多困難，多恐怖...
苦讀幾年後的結果，就是只要稍微準備一下就可以一次考上四大研究所...

這幾天他都到台大去找教授談，晚上他約了我見面。和我分享一些這陣子考試的見聞～

覺得他實在很了不起！也真為他感到開心！！
當然，還有六月的後西醫考試也加油！
