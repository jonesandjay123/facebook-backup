# 自有印象以來，每天騎youbike回家的租賃點正

自有印象以來，每天騎youbike回家的租賃點正對面就一直在施工～
直到前一陣子，才真正注意他們是到，原來是要弄一間Toyota的汽車展示中心。

然後，等我今天再次注意到時，竟然已經蓋完工且開張了？！

啥？！！
也太快了吧，前幾天不是還空盪盪的嗎？！

為此我特地走上天橋去看一看～

奇怪，到底是我注意力太差，還是他們動作實在太快！

雖然覺得他們應該是趁著上週末的時間做佈置的，但實在還是很想知道是怎麼弄的，裝潢效率竟然這麼好！！！
尤其我一直很好奇，他們這種展示中心的車子到底都是怎麼弄上去的...
